# Aplikasi Daftar Kontak

## Tugas Pertemuan 2 — Pemrograman Mobile

Aplikasi ini dibuat untuk memenuhi tugas Pertemuan 2 pada materi *Layout, ListView, dan Navigasi Antar Halaman*.

## Fitur
1. Menampilkan daftar seluruh kontak.
2. Setiap kontak berisi informasi nama, nomor telepon, dan email.
3. Avatar menampilkan karakter pertama dari nama kontak.
4. Tampilan daftar menggunakan `ListView.builder`.
5. Setiap item dikemas menggunakan komponen `ListTile`.
6. Mengetuk kontak akan mengarahkan pengguna ke halaman detail.
7. Halaman detail menyajikan informasi kontak secara menyeluruh.
8. Menyediakan tombol kembali untuk menuju ke halaman utama.
