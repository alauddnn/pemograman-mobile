# Tugas Pertemuan 2 — Daftar Kontak

## Deskripsi
Membuat aplikasi Flutter *Daftar Kontak* yang menampilkan daftar kontak dan halaman detail setiap kontak.

## Ketentuan Tugas
Aplikasi harus memiliki:
- Minimal 6 kontak.
- Nama kontak.
- Nomor telepon.
- Email.
- Data disimpan dalam list yang berisi objek class.
- Halaman utama menggunakan `ListView.builder`.
- Setiap kontak menggunakan `ListTile`.
- Avatar menampilkan huruf pertama nama.
- Kontak dapat ditekan untuk membuka halaman detail.
- Halaman detail menampilkan seluruh data kontak.
- Tersedia tombol kembali.
