# Latihan Mandiri 2 — Menambahkan Deskripsi

## Tujuan
Menambahkan properti deskripsi pada class Makanan dan menampilkan deskripsi pada halaman detail.

## Perubahan
Class Makanan sekarang memiliki tiga properti:
- nama
- harga
- deskripsi

Ketika menu ditekan, aplikasi membuka halaman detail yang menampilkan nama, harga, dan deskripsi.

## Konsep yang Dipelajari
- Menambahkan properti pada class.
- Constructor dengan beberapa parameter.
- `Navigator.push`.
- Mengirim object ke halaman detail.
