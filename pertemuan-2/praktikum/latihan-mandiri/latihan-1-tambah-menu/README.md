# Latihan Mandiri 1 — Menambahkan Menu

## Tujuan
Menambahkan tiga menu baru ke `daftarMenu` dan memastikan daftar dapat di-scroll menggunakan `ListView.builder`.

## Menu Tambahan
Tiga menu yang ditambahkan:
- Bakso
- Soto Ayam
- Ayam Geprek

## Hasil
Daftar menu sekarang berisi tujuh item dan dapat di-scroll.

## Konsep yang Dipelajari
- List data menggunakan class Dart.
- `ListView.builder` untuk menampilkan daftar.
- Daftar dapat di-scroll ketika jumlah item bertambah.
