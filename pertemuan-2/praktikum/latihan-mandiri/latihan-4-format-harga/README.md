# Latihan Mandiri 4 — Format Harga

## Tujuan
Mengubah tampilan angka harga menjadi format ribuan menggunakan pemisah titik melalui fungsi kustom.

## Contoh Penerapan
- 15000 → 15.000 (Nasi Uduk, Bakso)
- 12000 → 12.000 (Mie Ayam)
- 4000  → 4.000 (Es Jeruk)
- 20000 → 20.000 (Ayam Sayur)
- 19000 → 19.000 (Soto Kambing)
- 10000 → 10.000 (Ayam Sayur)

## Konsep
Menggunakan fungsi khusus untuk memformat angka nominal harga agar lebih rapi dan mudah dibaca oleh pengguna.
