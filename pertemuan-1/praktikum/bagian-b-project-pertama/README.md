# Bagian B — Membuat Proyek Flutter Pertama

## Tujuan
Membuat dan menjalankan proyek Flutter pertama.

## Langkah 1 — Membuat Project
Jalankan:
```bash
flutter create praktikum_1

```

## Langkah 2 — Masuk ke Project

```bash
cd praktikum_1

```

## Langkah 3 — Menjalankan Project

```bash
flutter run

```

Pilih perangkat Android yang tersedia apabila diperlukan.

## Hasil

Flutter akan menjalankan aplikasi counter bawaan.
Aplikasi memiliki tombol + yang dapat digunakan untuk menambah angka.

## Checkpoint

* [ ] Project berhasil dibuat.
* [ ] Project berhasil dijalankan.
* [ ] Aplikasi counter bawaan tampil.
* [ ] Tombol + dapat menambah angka.
