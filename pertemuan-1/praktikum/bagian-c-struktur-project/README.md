# Bagian C — Mengenal Struktur Proyek

## Tujuan
Memahami file dan folder penting pada proyek Flutter.

## Struktur Dasar

```

project/
├── android/
├── ios/
├── lib/
│   └── main.dart
├── test/
├── pubspec.yaml
└── ...

```

## File dan Folder Penting

### lib/main.dart
Merupakan file utama tempat penulisan kode aplikasi Flutter.

### pubspec.yaml
Digunakan untuk konfigurasi project, dependensi, dan aset.

### android/
Berisi kode dan konfigurasi untuk platform Android.

### ios/
Berisi kode dan konfigurasi untuk platform iOS.

### test/
Digunakan untuk menyimpan berkas pengujian.

## Kesimpulan
lib/main.dart merupakan file yang paling sering digunakan pada tahap awal pembelajaran Flutter karena berisi kode utama aplikasi.
