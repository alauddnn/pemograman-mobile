# Bagian A — Input Dasar dengan TextField

## Tujuan
Menerima input nama menggunakan `TextField` dan menampilkan sapaan.

## Konsep
- `TextField`
- `TextEditingController`
- `setState()`
- `dispose()`

## Alur
```text
Input nama
   ↓
Controller membaca teks
   ↓
Tombol Sapa
   ↓
setState()
   ↓
Sapaan ditampilkan

```

## Checkpoint

Mengetik nama lalu menekan tombol Sapa menampilkan sapaan di bawah input.
Controller juga dilepas menggunakan `dispose()`.
