# Bagian B — Form dengan Validasi

## Tujuan
Membuat form pendaftaran dengan beberapa input dan validasi.

## Input
- Nama lengkap
- Email
- Jurusan
- Persetujuan ketentuan

## Validasi
- Nama wajib diisi.
- Email harus mengandung `@`.
- Jurusan wajib dipilih.
- Tombol Daftar aktif setelah checkbox persetujuan dicentang.

## Checkpoint
1. Tombol Daftar nonaktif sebelum checkbox dicentang.
2. Nama kosong menghasilkan pesan error.
3. Email tidak valid menghasilkan pesan error.
4. Jurusan wajib dipilih.
5. Data valid menghasilkan SnackBar.
